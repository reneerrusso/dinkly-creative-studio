# Used Storylines

`data/used_storylines.json` is permanent originality memory. A record preserves the full concept, format, generated/approved/used dates, prompt and generation IDs, published post IDs, performance data, feedback, source batch, source trend, and status.

Every future batch compares candidates against Used Storylines, approved work, recent batches, passed concepts, published work, and Story Library. Exact normalized matches and materially similar titles are excluded. Related ideas are allowed only when the emotional or visual execution is meaningfully different.

Reuse must be intentional. **Duplicate as variation** creates a visibly labeled candidate based on a chosen used record; the system never silently regenerates it.
