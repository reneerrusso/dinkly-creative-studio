# DINKLY Social Learning

## Purpose

This is the living human-readable report for evidence collected in `data/social_posts.json` and reviewed learnings stored in `data/social_learnings.json`.

The report must distinguish measured performance, observed creative traits, hypotheses, and unverified assumptions. It never invents missing metrics and never treats a single viral post as universal proof.

## Evidence rules

- Record unknown metrics as `null`.
- Do not calculate a rate when its numerator, views, or required denominator is missing.
- Do not calculate a rate when views are zero.
- Compare like with like when possible: same platform, similar posting period, similar format, and similar audience conditions.
- Treat platform changes, paid distribution, collaborations, and posting-time effects as possible confounders.
- Preserve old learnings when evidence changes. Mark contradictions explicitly and update confidence.

## Confidence standard

- **High:** multiple strong examples or a very large, well-matched performance gap.
- **Medium:** repeated signal with limitations or one unusually strong example supported by adjacent evidence.
- **Low:** early hypothesis, isolated example, incomplete data, or weak comparison.
