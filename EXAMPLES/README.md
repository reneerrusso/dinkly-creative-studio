# Approved Example Library

These examples demonstrate how the DINKLY system turns a familiar routine into a concise production brief. They are creative references, not measured performance claims.

Each example records:

- Approved format
- Emotional insight
- Left and right scenes
- Visual direction
- Relevant execution risks
- Why the structure is reusable

Do not copy an example unchanged. Use the Story Library and Social Learning evidence to create an adjacent idea with a meaningfully different emotional angle, act of care, camera view, or seasonal context.

No social metrics are attached to these files. Add measured post data only through `scripts/ingest_social_post.py`.
