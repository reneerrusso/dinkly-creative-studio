# DINKLY Comic Brain

This repository is the source of truth for creating DINKLY comics, production prompts, and future character-IP work.

## Required reading order

Before creating or reviewing a DINKLY comic, read these sources in order:

1. [`DINKLY_PROMPT_GUIDE.md`](DINKLY_PROMPT_GUIDE.md) — current production rules and prompt structure.
2. [`brain/DINKLY_BRAND_BIBLE_v1.0.md`](brain/DINKLY_BRAND_BIBLE_v1.0.md) — brand mission, emotional world, personality, and long-term vision.
3. [`references/dinkly_young.png`](references/dinkly_young.png) — authoritative character model reference.

## Source priority

- The reference image is absolute for character identity, anatomy, proportions, markings, colors, and distinguishing features.
- The Prompt Guide is authoritative for current comic execution: layout, emotional contrast, typography, environment, and quality checks.
- The Brand Bible is authoritative for mission, tone, emotional intent, story selection, and licensing fit.
- When an older example conflicts with a newer production rule, follow the newer and more specific rule while preserving the Brand Bible's emotional North Star.

## Character identity lock

- **Dinka** is the girl on the left of the reference image. She has a red bow, ponytail, and eyelashes.
- **Dinko** is the boy on the right of the reference image. He has exactly two hair tufts and no bow or ponytail.
- Dinka and Dinko must remain the same body size and scale in production artwork.

## Comic creation gate

Every concept must pass four tests before a production prompt is written:

1. Does it make an ordinary shared moment feel warmer?
2. Is the emotion understandable in under two seconds without dialogue?
3. Does it preserve the locked character models and current production rules?
4. Could it naturally live as a sticker, card, plush, book image, or licensed product?

If any answer is no, improve the concept before generating artwork.
